# 히스이 조사대 (레전드 아르세우스 스타일 팬 RPG, 엔트리)

레츠고 프로젝트(상위 폴더)와 **별개 게임**입니다. 같은 엔진·생성기를 분기해 히스이 세계관으로 새로 만들었습니다.

- 파일: `build/Legends_Hisui_Survey_1.0.ent` (엔트리에서 불러오기)
- 시작: `1` 새 게임 → 파트너 선택(나몰빼미/브케인/수댕이) → 쥬빌라이프 마을
- 도감 235종(히스이 폼 포함), 기술 351개, 노블 5 + 기라티나·디아루가·펄기아 + 아르세우스, 은하단 간부 4명
- 알파 포켓몬(필드 12%, Lv+8, 크게 표시, 포획률 -40%), 몰래 접근(느리거나 멈춘 포켓몬) 포획률 +30%
- **도감 조사:** 포획 +2, 배틀 처치 +1, 알파 포획 +7이 종별 조사 점수로 쌓이고, 도감 상세에 조사 단계가 표시됩니다. 합계 25/60/120/220/400점마다 보상(메뉴 10에서 확인)
- **요청 게시판:** 마을마다 게시판(NPC)이 있고 임무 3개(포획 N마리, 타입별 포획, 배틀 승리)와 보상을 받는다. 12개 마을 36개 임무
- **노블 투척 진정:** 노블 5명과 싸우기 전에 돌진 방향을 맞혀 피하고 타이밍 막대로 진정 구슬을 던진다. 분노 게이지를 0으로 만들면 노블이 약해진 채(체력 60%) 시작한다. 구슬은 상점에서 판다
- **탈것(메뉴 9):** 클리버 진정 후 사슴(한 번에 두 칸), 윈디 진정 후 라프라스(물 위 이동)
- 연출: 페이드 전환, 보스·알파 시네마 컷인, 포획 볼 궤적·흔들림·폭발, 피격 흔들림, 기절, 레벨업·진화 플래시, 날씨·시간 틴트와 비·눈·모래 입자, 타이틀 이미지, 효과음 11종
- 조작: 터치 버튼(방향·확인·메뉴·파트너) 또는 방향키/WASD, Space/Z, M, P. 메뉴는 숫자 입력창

## 검증 (자체 블록 실행기 기준)
엔진 테스트 10,558건, 블록 단위 테스트 473건, 엔진 플레이 기록을 블록에서 한 걸음씩 재생(빠른·일반 경로), 패킹된 `.ent` JSON 재생 모두 통과.
**엔트리에서의 실제 실행은 사용자가 확인한 레츠고 판만 검증됨. 이 파일은 같은 변환기로 만들었지만 직접 열어본 적은 없다.**

## 한계
스토리·인물·지역명은 오리지널이며 구조만 참고했다. 퍼즐은 스위치 순서 변형, 맵은 절차 생성, 스프라이트는 PokéAPI 임시 사용(공개 배포 전 교체 필요).
재생성: `cd arceus && python3 tools/fetch_dex.py && python3 tools/fetch_moves.py && python3 tools/build_world.py && python3 tools/make_assets.py && python3 tools/assemble.py`


## PC 조작키 (엔트리 작품 화면을 한 번 클릭해 포커스를 준 뒤)
| 동작 | 키 |
|---|---|
| 이동 | 방향키 ↑↓←→ 또는 W A S D |
| 확인 / 말 걸기 / 타이밍 막대 멈추기(포획·구슬 던지기) | Space, Z, Enter |
| 메뉴 | M |
| 파트너 부르기(힌트, 숨은 통로 열기) | P |
| (미구현) 취소 | X, Esc — 현재 메뉴 닫기는 `0`을 입력 |

- 메뉴·선택은 화면 아래 입력창에 **숫자**를 입력하고 Enter.
- 메뉴(M): 1 파티 · 2 가방 · 3 도감 · 4 보관함 · 5 세이브 · 6 설정 · 7 닫기 · 8 힌트 · 9 탈것 · 10 조사 현황.
- 모바일은 화면의 터치 버튼(방향·확인·메뉴·파트너)을 쓴다.
