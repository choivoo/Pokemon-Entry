## 현재 구조
- `tools/world_def.py` 지역·퀘스트·인물 (사람이 쓴 설계) → `tools/build_world.py` → `data/*.json`
- `engine/engine.js` 기준 엔진(전투·포획·규칙·저장), `engine/sim.js` 전체 플레이 봇, `tests/test.js` 불변식 6,148건
- `tools/bdsl.py` 블록 생성 DSL + 블록 인터프리터, `tools/game_{a..e}.py` 엔트리 블록 로직, `tools/assemble.py` 패킹과 정적 검증
- `tests/test_blocks.py` 엔진 플레이 기록을 블록에서 재생(패킹된 .ent의 JSON도), `tests/test_blocks2.py` 블록 단위 테스트
- 전체 재생성·검증: `tools/run_all.sh` (약 5분)

## 다음 작업의 첫 진입점
1. 엔트리에서 `build/Pokemon_Pikachu_Kanto_Journey_1.0.ent`를 열어 오류가 나는 블록 이름·파라미터를 확인하고 `tools/bdsl.py`의 `blk(...)` 호출과 `Interp`의 블록 표를 맞춘다. 블록 구조 오류가 나는 곳은 대부분 `tools/bdsl.py`의 DSL 함수 한 곳에서 고쳐진다.
2. 엔트리에서 열린 뒤에는 `QA_REPORT.md`의 미구현 목록 중 트레이너 시선 판정, 움직이는 야생 포켓몬, 그래픽 메뉴를 우선한다.
3. 길이를 더 늘리려면 새 장 단위 콘텐츠가 필요하다. 현재 필수 단계 206개.
