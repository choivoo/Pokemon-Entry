# QA 보고서

## 0. 먼저 읽을 것

- **엔트리 편집기에서 `.ent`를 열어보지 못했다.** 이 작업 환경에는 엔트리 편집기·브라우저용 엔트리 런타임이 없다. 블록 종류 이름과 파라미터 순서는 엔트리 프로젝트 형식에 대한 기억에 기반한 **추정**이다. 아래 모든 '통과'는 **자체 블록 인터프리터**(`tools/bdsl.py`)가 내가 가정한 블록 의미를 재현한 결과이며, 엔트리 자체의 동작을 증명하지 않는다.
- 첫 엔딩 필수 경로 목표는 사용자 요청으로 **사람 기준 최대 10시간**으로 조정했다. 구현한 필수 단계(206개)를 봇이 플레이한 추정은 필수 경로 약 2.6~3.9시간(육성 반복 제외), 육성까지 합치면 약 9~16시간이다. 사람은 탐색·읽기·길 찾기·팀 구성에 더 걸리므로 **대략 2~3배(약 7~10시간)로 짐작하지만 실측은 못 했다.** 시간 채우기용 반복(대기·왕복 강요·같은 포켓몬 수집 강제)은 만들지 않았다. 원래 기획의 114시간 예산은 달성하지 못했다.
- 사람이 직접 플레이한 시간은 측정하지 못했다. 아래 시간은 모두 봇 시뮬레이션이다(가정: 한 칸 0.22초, 전투 한 턴 5초, 대사 한 줄 3초, 볼 던지기 7초, 센터·상점 메뉴 20초).

### 검증 범위 요약
- 맵 176화면의 모든 출구가 도달 가능하고 도착 칸이 문이 아니며 반대 방향 출구가 있다(즉시 되돌아가기 방지).
- 모든 NPC 옆 칸에 도달할 수 있고, 모든 규칙의 플래그·트레이너·아이템 참조가 존재한다.
- 필수 단계 "+str(sum(len(v) for v in Q.values()))+"개를 봇이 끝까지 해결해 8개 배지, 로켓단 본부, 리그, 엔딩까지 도달한다(시드 48회 중 실패 0회: 빠른 경로 24, 일반 경로 24, 단서 순서 뒤집기 포함).
- 블록 프로그램이 같은 플레이를 한 걸음씩 재현하며 위치·플래그 수·최종 플래그·배지·엔딩이 일치한다(빠른 경로 약 6.3만, 일반 경로+단서 뒤집기 약 3만 이벤트).
- 보상 중복 지급 없음: 엔딩 후 모든 NPC에게 두 번씩 말을 걸어도 돈·가방·파티·플래그가 변하지 않는다(엔진·블록 둘 다).
- 저장 코드는 왕복 시 동일하며, 검사값 불일치·버전·알 수 없는 맵·벽 위 좌표·음수 돈·음수 수량·없는 포켓몬·HP 초과·플래그 길이 오류를 모두 거부하고 이때 현재 진행을 바꾸지 않는다.

## 3. 알려진 제약과 미구현 (정직한 목록)

**엔트리 관련**
- `.ent`를 엔트리에서 열어보지 못했다. 열기 실패·블록 오류가 있을 수 있고, 그 경우 `docs/STATUS.md`의 절차로 오류 블록을 알려 주면 생성기(`tools/bdsl.py` 블록 이름 표)를 고치는 것이 가장 빠르다.
- 한 맵을 도장(스탬프) 220개로 그린다. 엔트리 실제 성능은 측정하지 못했다.
- 음악 재생 블록(`sound_something_wait_with_block`)과 재시작 방식의 BGM 전환은 미검증 추정이다. 소리 없이도 조작과 클리어는 가능하다.
- 프로젝트 용량 약 0.6MB(스프라이트 151장을 두 오브젝트가 공유). 실제 엔트리 용량 한도는 확인하지 못했다.

**기획 대비 구현 상태 (최종)**
- 구현: 체육관별 서로 다른 퍼즐 구조(3·4·5스위치 순서, 두 단서판 합쳐 읽기, 함정 스위치, 선택 분기). 다만 시각 메커니즘(수문·회로 그림)이 아니라 모두 '스위치를 읽고 누르기'의 변형이다.
- 구현: 트레이너 시선 판정(같은 줄·열 3칸, 벽이 사이에 없을 때) — 엔진·블록 동일, 봇 플레이 기록 재생으로 일치 확인.
- 구현: 라이벌·관장·사천왕·일반 트레이너가 패배 후 다른 대사로 재도전(패배 플래그).
- 구현: 야생 포켓몬이 필드에 보이고(최대 2마리, 종별 아이콘) 출현표의 행동(느림·멈춤·도망·다가옴)대로 움직인다. 낮/밤(300걸음 주기)에 따라 유령·독·에스퍼·악 타입 출현 비중이 바뀐다.
- 구현: 능력치 단계 변화 기술(공격·방어·특공·특방·스피드, ±6, 자신/상대 대상, 확률 부가효과) 16종 포함 기술 105개. 교체 시 단계 초기화.
- 구현: 피카츄 호감도(걸음 25마다·호출 시 증가, 최대 100): 10 이상이면 호출 시 이 화면의 미완료 단계 개수·방향을 알려 주고, 20/50 이상에서 어두운 곳 시야가 넓어지며, 30 이상이면 피카츄 기술 피해 +10%. 필수 진행에는 영향 없음.
- 구현: 어두운 맵(동굴·지하창고·침몰선·본부)은 플레이어 주변 반경 3칸(호감도에 따라 4~5)만 그린다.
- 구현: 글자 속도·음량·피격 깜빡임 설정, 파티·가방 패널(텍스트 상자), HP 막대, 걷기 2프레임(플레이어·피카츄), 피격 깜빡임, 지역별 후일담 NPC 12곳, 지역 첫 도착 피카츄 대사.
- 미구현: 다턴 기술(차징·반동 턴), 명중·회피 단계, 날씨·특성, 도로별 고유 고저차와 숨은 통로(맵은 절차 생성), 방향별 포켓몬 걷기 스프라이트(필드의 야생 포켓몬은 정면 스프라이트를 축소한 아이콘이다), 본격 애니메이션(투구 궤적·진화 연출 등), 그래픽 메뉴 전체(HP 막대와 패널만), 시간대의 실제 시계 연동(게임 안 걸음 수 기준).
- 교환 진화 4종은 레벨 40~46 진화로 대체했다. 도감 151종은 야생·선물·진화로 전부 얻을 수 있다(자동 검사). 전설 5종은 엔딩 후 고정 조우다.
- 스프라이트 사용 범위는 확인하지 못했다(`docs/SOURCES.md`). 공개 배포는 하지 않았다.

**봇·수치**
- 시간 수치는 봇이 만든 값이다. 사람은 팀 구성과 육성에 더 적게 또는 더 많이 걸릴 수 있다. 봇은 상성 기반으로 팀을 모으고 레벨을 올리며, 여러 번 전멸 후 재도전한다.
