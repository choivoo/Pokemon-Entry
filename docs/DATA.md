## 8. 세이브 코드 형식 `EK1`

`EK1|맵번호|x|y|돈|배지비트|클리어|마지막센터맵|플래그문자열(273자,0/1)|도감문자열(151자,0/1/2)|가방(점구분 19개)|파티(~구분)|보관함(~구분)|검사값`

개체 = `종:레벨:경험치:HP:상태:기술1~4:PP1~4`. 검사값은 문자 코드 가중 합산(mod 1000003). 읽을 때 전체를 검증한 뒤에만 적용하며 실패하면 현재 진행을 건드리지 않는다.
