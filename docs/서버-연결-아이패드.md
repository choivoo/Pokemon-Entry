# 서버(Supabase) 연결하기 — 아이패드로 따라 하기

이 설정을 한 번만 하면 **어느 기기에서든 같은 계정**으로 로그인하고, **같은 반 친구들과 랭킹**을 겨룰 수 있어요.
아이패드 Safari 만 있으면 되고, 컴퓨터는 필요 없어요. 약 15분 걸려요.

> 준비물: GitHub 계정(이 저장소 주인 계정) · 아이패드 Safari
> 화면 이름은 Supabase / GitHub 가 조금씩 바꿀 수 있어요. 비슷한 이름의 메뉴를 찾으면 돼요.

## 1단계. Supabase 프로젝트 만들기

1. Safari 에서 **supabase.com** 에 들어가 **Start your project** 를 눌러요.
2. **Continue with GitHub** 로 로그인해요. (GitHub 계정이 있으면 가장 쉬워요)
3. **New project** 를 눌러요. (처음이면 Organization 이름을 물으면 아무 이름이나 적어요)
4. 이렇게 채워요.
   - **Name**: `pokerogue-edu` (아무 이름이나 OK)
   - **Database Password**: **Generate a password** 를 누르면 만들어 줘요. 어디에 적어 두세요. (게임에는 넣지 않아요)
   - **Region**: **Northeast Asia (Seoul)** 를 골라요.
5. **Create new project** 를 눌러요. 1~2분 기다리면 준비돼요.

## 2단계. 서버 설정(SQL) 넣기

1. 새 Safari 탭에서 이 저장소의 **`supabase/schema.sql`** 파일을 열어요.
   (GitHub 저장소 → `supabase` 폴더 → `schema.sql`)
2. 파일 화면 오른쪽 위에서 **두 장이 겹친 모양의 "Copy raw file" 아이콘**을 눌러요. 전체가 복사돼요.
3. Supabase 탭으로 돌아와서 왼쪽 메뉴의 **SQL Editor** → **New query** 를 눌러요.
   (아이패드가 세로면 왼쪽 위 ☰ 를 눌러야 메뉴가 보여요)
4. 입력창을 **길게 눌러서 "붙여넣기"** 를 해요.
5. 오른쪽 아래 **Run** 을 눌러요.
   - "destructive operations(되돌릴 수 없는 작업)" 경고가 나오면 **Run this query** 를 눌러요. (옛 규칙을 지우고 다시 만드는 줄이 있어서 그래요)
   - 맨 아래에 **Success. No rows returned** 가 보이면 성공이에요.
6. 왼쪽 **Table Editor** 를 눌러서 `edu_users`, `edu_saves`, `scores` 표가 보이면 잘 된 거예요.

## 3단계. 주소와 키 복사하기

1. 왼쪽 맨 아래 **Project Settings**(톱니바퀴)를 눌러요.
2. **Data API**(또는 **API**)에서 **Project URL** 을 복사해요. (`https://….supabase.co` 모양)
3. **API Keys** 에서 아래 중 **공개용 키 하나**를 복사해요.
   - **`anon` `public`** 키 (아주 긴 `eyJ…` 글자), 또는
   - **Publishable key** (`sb_publishable_…`)

> 🚫 **`service_role` 키나 `secret` 키(`sb_secret_…`)는 절대 쓰지 마세요.** 그 키가 있으면 누구나 모든 정보를 볼 수 있어요.
> (실수로 넣어도 게임이 알아보고 사용을 거부하게 만들어 두었어요.)

## 4단계. GitHub 에 넣기

1. Safari 에서 GitHub 의 이 저장소를 열고 **Settings** 탭을 눌러요.
   (탭이 안 보이면 오른쪽 `…` 를 눌러요)
2. 왼쪽 **Secrets and variables → Actions** 를 눌러요.
3. **Variables** 탭 → **New repository variable** 을 눌러서 두 개를 만들어요.

   | Name | Value |
   | --- | --- |
   | `SUPABASE_URL` | 3단계에서 복사한 Project URL |
   | `SUPABASE_ANON_KEY` | 3단계에서 복사한 공개용 키 |

   (Secrets 탭이 아니라 **Variables** 탭이에요!)

## 5단계. 다시 배포하기

1. 저장소의 **Actions** 탭 → **포케로그 국영수(초등) - GitHub Pages 배포** → **Run workflow** → **Run workflow**.
2. 초록색 체크가 뜨면(약 4~5분) 끝이에요.

## 잘 됐는지 확인하기

1. 게임 주소를 열고 **등록**으로 새 계정을 만들어요. (서버 연결 전에 만든 계정은 같은 아이디·비밀번호로 로그인하면 **자동으로 서버로 옮겨져요**)
2. Supabase → **Table Editor → `edu_users`** 에 방금 만든 계정이 보이면 성공이에요.
3. 다른 기기(폰, 다른 아이패드)에서 같은 아이디로 로그인해 보세요. 학습 설정과 저장해 둔 게임이 그대로 나와요.

## 아이패드로 게임할 때 팁

- **홈 화면에 추가**: Safari 에서 공유(□↑) → **홈 화면에 추가**. 주소창 없이 꽉 찬 화면으로 해요.
- 가로 방향이 문제를 풀기에 편해요. 세로도 잘 맞아요.
- 서버를 연결하지 않으면 계정이 Safari 안에만 저장돼요. Safari 는 **일주일 동안 안 쓰면 사이트 데이터를 지울 수 있어서**, 서버 연결을 꼭 추천해요.

## (선택) 학교 검색을 더 잘 되게 하기

학교 검색(교육부 NEIS)은 인증키 없이도 되지만 한 번에 5개씩만 보여 줘요(지역 고르기 · "더 보기"로 해결 가능).
인증키가 있으면 한 번에 많이 보여요. **open.neis.go.kr** 에서 회원가입 후 인증키를 신청해서, 4단계처럼 Variables 에 `NEIS_KEY` 로 넣으면 돼요.

## 문제가 생기면

| 증상 | 확인할 것 |
| --- | --- |
| 계정을 만들어도 Table Editor 에 안 보여요 | 4단계 변수 이름 오타(`SUPABASE_URL`, `SUPABASE_ANON_KEY`), Variables 탭인지, 5단계 다시 배포했는지 |
| 로그인할 때 "서버에 연결하지 못했어요" | Project URL 이 `https://` 로 시작하는지, 프로젝트가 일시정지(Paused)되지 않았는지 (무료 프로젝트는 1주일간 안 쓰면 멈춰요 → Supabase 에서 **Restore**) |
| SQL 이 실패해요 | 파일 **전체**를 복사했는지 (맨 위 `-- 포케로그…` 부터 맨 아래 `-- #endregion` 까지) |
| 랭킹에 내 점수가 안 올라가요 | 학습 설정에서 **랭킹 동의**를 체크했는지 |
